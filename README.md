## 📌 Overview

This repository documents the complete journey of my Data Analytics Internship at ApexPlanet Software Pvt. Ltd. Over 60 days, I worked through five progressive tasks — from raw data wrangling to a fully integrated capstone portfolio — building hands-on skills in data cleaning, exploratory analysis, dashboarding, statistical validation, and data storytelling.

Each task below links to its dedicated repository containing code, reports, and supporting deliverables, along with a LinkedIn video walkthrough.

---

## 🗂️ Task Summary

### Task 1: Data Immersion & Wrangling
**Timeline:** 10 Days

**Objective:** Get acquainted with the provided dataset and master the foundational step of any analysis — acquiring, cleaning, and preparing data.

**What I Did:**
- Accessed and explored a key dataset (sales transactions / website analytics / customer data)
- Created a **data dictionary** documenting each variable's meaning, type, and business relevance
- Performed data quality assessment — identified missing values, duplicates, inconsistent formatting, and outliers
- Wrote cleaning scripts (Python/Pandas or SQL) to resolve data quality issues
- Performed transformations: standardized date formats, categorized free-text fields, and engineered new features (e.g., "Customer Age" from "Date of Birth")
- Produced a final, analysis-ready dataset

**Deliverables:**
- 🔗 [Task 1 Repository](#) — Data dictionary, cleaning script, cleaned dataset
- 🎥 [LinkedIn Video](#) — 3–5 min walkthrough of data issues and cleaning process

---

### Task 2: Exploratory Data Analysis (EDA) & Business Intelligence
**Timeline:** 14 Days

**Objective:** Uncover patterns, trends, and relationships in the data while building proficiency in SQL for data extraction and dashboarding.

**What I Did:**
- Calculated descriptive statistics and built univariate visualizations (histograms, bar charts)
- Answered 5–7 business questions using SQL — including filtering, aggregation, and multi-table joins (e.g., top products by revenue, monthly user acquisition trends)
- Conducted multivariate analysis using scatter plots, heatmaps, and pair plots to explore relationships (e.g., marketing spend vs. sales)
- Designed a **static dashboard mock-up** (PowerPoint/Excel) proposing key KPIs to track

**Deliverables:**
- 🔗 [Task 2 Repository](#) — EDA report, SQL queries with results
- 🎥 [LinkedIn Video](#) — 5–7 min showcase of key insights and complex queries

---

### Task 3: Deep-Dive Analysis & Interactive Dashboarding
**Timeline:** 12 Days

**Objective:** Solve complex, multi-faceted business problems through deep-dive analysis and build a live interactive dashboard.

**What I Did:**
- Formally defined 3–5 core KPIs with formulas and business rationale (e.g., Conversion Rate, Customer Churn Rate, Average Order Value)
- Conducted a deep-dive analysis in one focus area:
  - Cohort Analysis (customer retention & lifetime value), **or**
  - Funnel Analysis (user drop-off in a key process), **or**
  - Segmentation Analysis (customer segmentation via clustering/business rules)
- Built a fully interactive dashboard using a BI tool (Tableau / Power BI / Looker Studio) surfacing core KPIs

**Deliverables:**
- 🔗 [Task 3 Repository](#) — Deep-dive report, link to live dashboard
- 🎥 [LinkedIn Video](#) — 5–7 min demo of interactive dashboard and key findings

---

### Task 4: Data Storytelling & Statistical Validation
**Timeline:** 16 Days

**Objective:** Synthesize all prior analysis into a compelling business narrative, backed by statistical rigor.

**What I Did:**
- Structured findings from Tasks 1–3 into a cohesive narrative with objective, analysis, conclusions, and a call to action
- Built a professional, visual presentation deck focused on business impact
- Formulated a testable business hypothesis (e.g., "The new website layout led to a statistically significant increase in conversion rate")
- Performed statistical testing (T-test / Chi-squared test) and interpreted p-values and confidence intervals to draw business conclusions

**Deliverables:**
- 🔗 [Task 4 Repository](#) — Final presentation deck, hypothesis testing summary
- 🎥 [LinkedIn Video](#) — 7–10 min stakeholder presentation of insights

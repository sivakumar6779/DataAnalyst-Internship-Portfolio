# ApexPlanet 60 Days Data Analytics Internship

# Task 1: Data Immersion & Wrangling

## Project Overview

This project is part of the ApexPlanet 60-Day Data Analytics Internship.

The objective of Task 1 is to understand the dataset, assess data quality, clean the data, perform basic transformations, and prepare an analysis-ready dataset.

---

## Dataset

**Dataset Name:** Superstore Sales Dataset

The dataset contains information about:

- Orders
- Customers
- Products
- Sales
- Profit
- Quantity
- Discount
- Shipping
- Regions
- States

---

## Objectives

- Understand the dataset
- Create a Data Dictionary
- Identify missing values
- Remove duplicate records
- Convert date columns
- Create new features
- Detect outliers
- Prepare a clean dataset for analysis
